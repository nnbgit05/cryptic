# Cryptic

Cryptic is a locally hosted password manager built for secure credential storage and retrieval, with user-controlled hosting and a simple web interface.

## Features

- Local-first password manager
- User-hosted deployment
- Secure authentication flow
- Credential storage with persistent backend
- Session and state management with Redis
- Simple browser-based interface

## Tech Stack

- **Frontend:** JavaScript
- **Backend:** Node.js
- **Build Tool:** Vite
- **Database:** PostgreSQL
- **Cache / Session Store:** Redis

## Requirements

Before running Cryptic, make sure you have the following installed:

- [Node.js](https://nodejs.org/) 20 or newer
- [npm](https://www.npmjs.com/)
- [PostgreSQL](https://www.postgresql.org/)
- [Redis](https://redis.io/)
